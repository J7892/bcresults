Cloud Architecture & Data Sources

This election monitor runs 100% serverless in the cloud using GitHub's native ecosystem:

1 Elections BC & DataBC GIS

Official electoral boundary shapefiles & live voting results published by Elections BC.

2 GitHub Actions Cron

Python updater executes on a scheduled cron throughout election night, scraping & parsing district results.

3 Git Repo Storage

Results committed directly to data/results.json with automated timestamps.

4 GitHub Pages Hosting

Static dashboard served with zero hosting costs, high availability, and instant global CDN delivery.
